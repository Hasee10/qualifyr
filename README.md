# GTM Tool

Go-to-market tool. Project details and stack to be finalized.

## Layout

| Path | Purpose |
|------|---------|
| `docs/` | Requirements, design notes, decisions |
| `src/` | Application source |
| `tests/` | Automated tests |
| `scripts/` | One-off and maintenance scripts |
| `config/` | Environment / app configuration (no secrets) |
| `data/raw/` | Untouched input data (gitignored) |
| `data/processed/` | Derived data (gitignored) |
| `assets/` | Static files: images, templates, fonts |
